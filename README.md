# Shakti Dental Clinic

A modern minimalistic  dental clinic website built with Next.js, featuring clinic information, services, doctor profiles, appointment/contact options, and a responsive user interface.This is just the frontend with responisve ui design .

## Tech Stack

* Next.js
* React
* TypeScript
* Tailwind CSS

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.
